### 🚀 Featured Project

#### AuditApp — Audit Management System

A web-based internal audit management application developed to support audit workflows and improve the effectiveness, transparency, and documentation of internal audit activities.

**Key features:**
- 📊 Dashboard for monitoring audit activities and findings.
- 📋 Audit planning, implementation, and working paper management.
- 📝 Audit findings, reports, and follow-up tracking.
- 💬 Real-time communication between auditors and auditees.
- 📁 Centralized document repository and audit documentation.
- 🔐 Role-based access for Admin, Auditor, and Auditee.

**Technologies:** React.js, Laravel, PostgreSQL, Laravel Sanctum, and Laravel Reverb.
